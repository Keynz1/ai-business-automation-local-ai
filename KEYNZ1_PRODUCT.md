# Keynz1 Business AI — Local Business Request Analyzer

**A Windows application for processing customer and business requests.**

Paste one business request, analyze its type and priority, review extracted contact details and a suggested reply, then export the record to Excel or CSV.

### Product demonstration

[Watch a real in-app analysis and Excel/CSV export demonstration (MP4)](docs/keynz1-review/demo.mp4)

The video shows a scripted walkthrough using the application's real analyzer and export functions; the output is not pre-rendered.

### Features

- Structured request type, priority, available contact details, summary and requested action
- Editable suggested reply to copy
- Excel and CSV exports
- Smart offline mode (built-in rules)
- Optional local Ollama AI support
- Windows 10/11, 64-bit; no Python needed for the packaged app

### Pricing

**8,900 KZT — one-time license for Keynz1 Business AI v1.0.** No subscription or paid external AI API is required. The buyer receives a downloadable ZIP containing the executable, documentation, sample data and commercial license.

### Limitations

Version 1.0 processes one pasted request at a time. It does **not** automatically read email inboxes, send messages, or integrate with CRM systems. Analysis and drafts should be reviewed by a person before business use. Optional local Ollama must be installed separately for local model mode; the built-in offline mode does not require it.
